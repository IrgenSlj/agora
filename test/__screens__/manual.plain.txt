
  ░▒▓█ agora receipt                                       check

  write, show and verify commit receipts

  USAGE
    agora receipt install | uninstall
    agora receipt write [<commit>] [--dry-run] [--no-sign]
    agora receipt show [<commit>]
    agora receipt verify [<commit>] [--trusted-from <rev>] [--fail-on-unknown]

  FLAGS
    --dry-run ··········· Print the receipt instead of writing
                           the note
    --no-sign ··········· Write an unsigned receipt
    --trusted-from ······ Read trusted keys from this revision
    --fail-on-unknown ··· Exit 3 when the commit has no receipt
    --json ·············· Output as JSON

  EXAMPLES
    agora receipt write
    agora receipt show HEAD~1
    git push origin refs/notes/agora

  ABOUT
    A receipt is an in-toto statement about one commit, stored
    as a git note under refs/notes/agora. It names the agent
    sessions that ran in this repository between the parent
    commit and this one, the hash of each session log at that
    point, and what they touched: files written and read,
    programs run, hosts reached, MCP tools called and calls
    denied. It also states what the host could not see. Never
    arguments or contents.

    A receipt states its signer level. `none` is a self-reported
    log that an agent with shell access could forge. A signed
    level verifies only against keys listed in
    .agora/signers.json at --trusted-from (default HEAD; CI uses
    the pull request base). `install` adds git hooks so every
    commit gets its receipt and every push sends them; without
    it, push receipts with `git push origin refs/notes/agora`.
    `write` refuses a log that does not verify. `verify` exits 1
    on an invalid receipt; a missing one is not established.
